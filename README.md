#### Проект: KeyDivide

Интернет-магазин по продаже эргономичных сплит-клавиатур с возможностью кастомизации.

**Стек технологий:**
- **Фронтенд:** HTML, CSS, JavaScript
- **Бэкенд:** Node.js + Express.js
- **База данных:** PostgreSQL

Главная особенность — **конфигурируемый товар**: у каждой клавиатуры свой набор доступных свитчей, свитч по умолчанию и количество переключателей в комплекте. **Итоговая цена** рассчитывается динамически:

```
цена = базовая_цена_клавиатуры + (цена_свитча × количество_свитчей)
```
При добавлении в корзину и оформлении заказа проверяется склад **и клавиатуры, и выбранных свитчей**. Заказ создаётся в **транзакции PostgreSQL** с блокировкой остатков, чтобы исключить продажу «в минус».

Дополнительная сложность — связанные сущности в БД: характеристики, комплектация, обложка и галерея изображений, доступные свitчи для каждой модели.

**Дополнительный функционал:**
- *Аутентификация*  - Passport.js (`local` + `jwt`), JWT в httpOnly cookies, bcrypt
- *Почта* - Nodemailer (подтверждение заказа) 
- *Тесты* - Node.js Test Runner (`node:test`) — unit-тесты сервисного слоя
